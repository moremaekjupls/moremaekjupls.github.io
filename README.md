# Khondamir Begmatov — личный сайт

Сайт на **Astro**: главная — полноэкранное видео с заголовком, плюс блог (EN)
и страница «Обо мне». Публикуется на GitHub Pages автоматически.

Адрес: **https://moremaekjupls.github.io**

---

## 1. Как добавить пост в блог (без кода)

Проще всего — через браузер: **https://app.pagescms.org**, вход через GitHub,
выбираете этот репозиторий. Конфиг `.pages.yml` уже лежит в корне, редактор
подхватится сам. Сохранение = коммит = сайт пересобирается.

Важно: **один пост = две записи**, русская и английская, с **одинаковым Post ID**.

Если правите файлами: посты лежат в `src/content/blog/`, по два файла на пост
(`имя.ru.md` и `имя.en.md`). Шапка каждого:

```yaml
---
title: "Заголовок"
excerpt: "Одна-две строки для списка блога."
pubDate: 2026-08-10          # YYYY-MM-DD
lang: "ru"                    # "ru" в .ru.md, "en" в .en.md
transId: "moy-post"          # одинаковый в обоих файлах, он же адрес /blog/moy-post
---
```

Черновик прячется строкой `draft: true` в шапке.

```

      PostArticleView.astro
  pages/                  ← маршруты; 404.astro — отдельная страница со своим видео
```

## 4. Главная

Полноэкранное видео `public/hero.mp4`, поверх — заголовок и две карточки:
свежий пост (подставляется сам) и цитата. На телефоне карточек нет, свежий
пост — в выдвижном меню. Прокрутки нет.

Заменить видео: положить новый `hero.mp4` (H.264, без звука, лучше до 2–3 МБ)
и обновить `hero-frame.jpg` — это кадр, который виден до загрузки ролика.
При системной настройке «уменьшить движение» видео не запускается.

Переходы между страницами — нативные `@view-transition` (Chrome, Edge,
Safari 18.2+); в остальных браузерах обычная навигация.

## 5. Запуск и публикация

Нужен Node.js 18+ и pnpm.

```bash
pnpm install      # один раз
pnpm dev          # локальный просмотр, http://localhost:4321
pnpm build        # сборка в dist/
```

Публикация автоматическая: любой push в ветку `main` запускает
`.github/workflows/deploy.yml`, который собирает сайт и публикует на GitHub Pages.
Смотреть ход — вкладка **Actions**.

Настройка Pages: **Settings → Pages → Source: GitHub Actions**.

## 6. Что выключено и как включить

**Форма обратной связи.** Пока `CONTACT.formspreeEndpoint` в `src/consts.ts` пуст,
форма на странице «Обо мне» скрыта автоматически. Чтобы включить: зарегистрируйтесь
на formspree.io, создайте форму, скопируйте её endpoint в это поле.

**Аналитика.** В `src/consts.ts` блок `ANALYTICS`: поставьте `enabled: true`,
выберите `provider` (`plausible` или `goatcounter`) и укажите `site`. Без кук и
без баннера согласия.

## 7. Шрифты и зависимости

Внешних CDN нет — ни один сторонний сервер не участвует в загрузке страницы.

**Шрифты** лежат в `public/fonts/` и подключаются блоком `@font-face` в начале
`global.css`: Geist — основной, Silkscreen — даты на карточке главной,
Instrument Serif — заголовок «Обо мне». Только латиница: для кириллицы
понадобятся отдельные файлы.

---

## 8. Если деплой упал

Открыть **Actions**, найти красный запуск, посмотреть, какой job упал.

- Упал **build** — ошибка в коде, лог покажет файл и строку.
- Упал **deploy** с `Timeout reached` — GitHub Pages не ответил вовремя. Это не
  ошибка проекта. Нажмите **Re-run jobs**. Лимит ожидания в workflow уже поднят
  до 30 минут.

Откатить неудачное изменение: вкладка **Commits**, нужный коммит, кнопка **Revert**.
