# Khondamir — личный сайт

Сайт-песочница на **Astro**: главная — полноэкранное видео, плюс блог,
история изменений и страница «Обо мне». Только английский.
Публикуется на GitHub Pages автоматически.

Адрес: **https://moremaekjupls.github.io**

---

## Как добавить пост

Новый файл в `src/content/blog/`, например `moy-post.en.md`:

```yaml
---
title: "Title"
excerpt: "One or two lines for the blog list."
pubDate: 2026-10-01          # YYYY-MM-DD
transId: "moy-post"          # адрес поста: /blog/moy-post/
---
```

Черновик прячется строкой `draft: true`.

## Что где

| Что | Файл |
|---|---|
| Ссылки на соцсети, домен, репозиторий | `src/consts.ts` |
| Главная: видео, заголовок, карточки, меню | `src/components/Hero.astro` |
| «Обо мне» | `src/components/views/AboutView.astro` |
| Цвета, типографика, все стили | `src/styles/global.css` (токены в `:root`) |
| Шрифт (один на весь сайт — Geist) | `public/fonts/geist-variable.woff2` + `@font-face` в начале `global.css` |
| Выборка постов, даты, ссылки | `src/lib/site.ts` |

```
src/
  layouts/        Screen.astro (главная), Base.astro (остальные страницы)
  components/     Hero, Header, Footer, SoundToggle, views/*
  lib/            site.ts — посты и утилиты, history.ts — git-история,
                  sound.ts — звуки интерфейса
  pages/          маршруты; sw.js.ts — service worker, offline.astro — офлайн
  content/blog/   посты
public/           видео с постерами, шрифты, иконки, манифест
```

## Фичи

**Время суток на главной.** Тон кадра меняется по местному времени: рассвет
(5–8), день (8–17), золотой час (17–20), сумерки (20–22), ночь. Над
заголовком — часы. Проверить любое время: `/?hour=23`. Настройки тона —
секция `TIME OF DAY` в `global.css`.

**История** (`/history/`). Собирается из git-лога при каждой сборке: итоги,
календарь активности и все изменения по месяцам. Сообщение коммита — это
то, что увидишь на странице, так что осмысленные сообщения делают историю
интереснее.

**Звуки интерфейса.** Синтезируются в браузере, файлов нет. Выключатель —
в подвале и внизу меню на главной, выбор запоминается. На iPhone подчиняются
беззвучному режиму. Звуки и их громкость — `src/lib/sound.ts`.

**Установка на телефон (PWA).** Safari → «Поделиться» → «На экран Домой»;
Chrome → «Установить приложение». Посещённые страницы открываются без сети.
Страницы всегда грузятся из сети, если она есть, — свежий деплой виден сразу.

## Запуск и публикация

Нужен Node.js 18+ и pnpm.

```bash
pnpm install
pnpm dev          # http://localhost:4321
pnpm build        # сборка в dist/
pnpm preview      # просмотр сборки (с service worker'ом)
```

Любой push в `main` запускает `.github/workflows/deploy.yml`: сборка и
публикация на GitHub Pages. Ход — вкладка **Actions**.

Если упал **deploy** с `Timeout reached` — GitHub Pages не ответил вовремя,
это не ошибка проекта: **Re-run jobs**.
