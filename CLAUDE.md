# CLAUDE.md

Личный сайт-песочница Khondamir. Единственный посетитель — владелец: сайт
существует ради удовольствия его делать и экспериментировать. Не предлагать
SEO, «конверсию», аудиторию, частоту постов, если об этом не спросили.
Отвечать по-русски.

## Стек и команды

Astro 4 (статическая сборка), pnpm, без фреймворков и UI-библиотек.

```bash
pnpm install
pnpm dev          # http://localhost:4321
pnpm build        # обязательно перед коммитом: сборка должна проходить без ошибок
pnpm preview      # отдаёт dist/
```

Деплой: push в `main` → `.github/workflows/deploy.yml` → GitHub Pages
(`https://moremaekjupls.github.io`). Сборка ~20 с, публикация до минуты.

Проверка в браузере: Playwright + Chromium из `/opt/pw-browsers`. Этот Chromium
не проигрывает H.264, поэтому `hero.mp4`/`404.mp4` в headless не грузятся —
это не баг сайта.

## Где что

- `src/layouts/Screen.astro` — главная (один экран, без шапки/подвала).
- `src/layouts/Base.astro` — внутренние страницы: шапка, подвал, scroll-reveal,
  «стекло» шапки при прокрутке.
- `src/components/Hero.astro` — главная: видео, заголовок, карточки, выдвижное
  меню со свайпом.
- `src/components/Header.astro` — шапка и мобильное меню внутренних страниц.
- `src/components/views/*` — содержимое страниц «Обо мне», блог, статья.
- `src/pages/404.astro` — самостоятельная страница со своими inline-стилями.
- `src/styles/global.css` — токены в `:root` и все стили, разбиты на секции
  (HERO, DRAWER, INNER PAGES, ABOUT, HOVER, PRESS FEEDBACK, SCROLL REVEAL,
  HOME ENTRANCE, USER PREFERENCES, PAGE TRANSITIONS).
- `src/content/blog/` — посты `имя.en.md` / `имя.ru.md`. Сайт показывает
  только EN; RU-файлы лежат, но не используются.
- `src/consts.ts` — ссылки на соцсети, форма, аналитика (обе выключены).
- `public/` — видео с постерами, шрифты (Geist, Silkscreen, Instrument Serif).

## Правила, которые уже стоили багов — не нарушать

1. **Никаких Astro `ViewTransitions` / `astro:page-load`.** SPA-роутер запускал
   скрипты страниц один раз, и кнопки «работали через раз». Переходы — нативный
   CSS `@view-transition`. Скрипты страниц выполняются при каждой загрузке.
2. **Не ставить `z-index`, `transform`, `filter`, `opacity < 1` на `.hero` и
   `.hero .layer`.** Любой контекст наложения запирает бургер (`z-index:50`)
   под выдвижной панелью (`45`), и меню нельзя закрыть крестиком. Эффект
   «отодвигания» при открытом меню делается только на `.hero video`.
3. **`.site-header` — `position:sticky; z-index:50`.** Не включать её в общие
   правила вида `main,.site-footer{position:relative;z-index:1}`: это уже
   однажды выключило sticky и спрятало мобильное меню под контент.
4. **Hover — только внутри `@media (hover:hover) and (pointer:fine)`**
   (секция HOVER). На телефоне отклик даёт `:active` (секция PRESS FEEDBACK).
   Пустой `touchstart`-обработчик в обоих layout'ах нужен iOS для `:active` —
   не удалять.
5. **Анимировать `transform` и `opacity`.** Кривые — токены `--ease-out`,
   `--ease-press`, `--ease-drawer`. Закрытие быстрее открытия. Любая новая
   анимация должна корректно выключаться в секции USER PREFERENCES /
   `prefers-reduced-motion`.
6. **Внутренние ссылки — со слэшем на конце** (`/blog/`, `/about/`); в
   компонентах через `localizeUrl()` / `withSlash()` из `src/i18n/ui.ts`.
   Без слэша GitHub Pages отвечает 301 на каждый клик.
7. **`view-transition-name` — только на блочных элементах и уникально на
   странице** (`post-${transId}`). Именованный элемент, разорванный на строки,
   отменяет переход целиком.
8. **Поля ввода — не меньше 16px** (иначе iOS зумит страницу). Отступы от
   выреза и полосы «домой» — через `--safe-t/-r/-b/-l`.
9. **Никаких сторонних CDN.** Шрифты и медиа — в `public/`. Видео: H.264,
   без звука, `faststart`, до ~2 МБ, плюс jpg-постер первого кадра.

## Гигиена CSS

Сайт уже вычищали от наслоений (блоки About v2/v3/v4, перебивавшие друг
друга; ссылки на несуществующие `@keyframes`; мёртвые компоненты). Поэтому:

- Меняешь блок — правь его на месте, а не дописывай ниже переопределение.
- Убрал элемент из разметки — удали его селекторы; добавил `animation:` —
  проверь, что `@keyframes` существует.
- Неиспользуемые компоненты удалять, а не оставлять «на потом».
